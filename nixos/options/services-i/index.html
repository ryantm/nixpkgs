services.i2pd.settings

Free-form main i2pd configuration. Options are passed to i2pd.conf. See https://i2pd.readthedocs.io/en/latest/user-guide/configuration/

Any free-formed option value can be substituted with contents of a provided file by setting it to { _secret = <path>; }. The file is read at runtime before i2pd service starts, file permissions are ignored.

Type: open submodule of nested (bool, int, string or list of bool, int or string)

Default: { }

Example:

{
  meshnets.yggdrasil = true; # Enable yggdrasil network support

  port = {
    _secret = "/run/secrets/i2pd-port";
    _secretPlaceholder = 0; # An optional placeholder value used when checking configuration
  };
}

Declared by: nixos/modules/services/networking/i2pd.nix

services.i2pd.settings.bandwidth

Set a router bandwidth limit: integer in KBps or alias. Note that integer bandwidth will be rounded. If not set, i2pd defaults to 32KBps.

Type: null or ((positive integer, meaning >0, or one of "L", "O", "P", "X") or (one of "2048KBps", "256KBps", "32KBps", "UNLIMITED") convertible to it)
